Manejo, protección y uso de datos personales

Manejo y protección de los datos

Los datos personales ingresados al sistema se utilizarán para gestionar el acceso y las funciones del portal. Su consulta debe limitarse a personas autorizadas y usarse únicamente para los fines institucionales correspondientes. Las contraseñas se almacenan mediante hash y no deben compartirse.

Los datos deben conservarse solo durante el tiempo necesario. Para solicitar acceso, corrección o eliminación, la persona deberá dirigirse al responsable institucional por los canales que establezca el Hospital de Clínicas.

Condiciones de uso por parte de la institución

El usuario debe proporcionar información correcta y mantener sus credenciales confidenciales. La institución utilizará los datos para administrar el acceso al sistema y prestar los servicios relacionados con sus funciones, no para fines ajenos a esos propósitos.

El acceso podrá limitarse cuando deje de ser necesario. Los datos solo podrán comunicarse a terceros cuando exista autorización, sea necesario para prestar el servicio o lo exija la normativa aplicable.

Nota: El Hospital de Clínicas debe revisar y aprobar este texto antes de usar el sistema con datos reales.
